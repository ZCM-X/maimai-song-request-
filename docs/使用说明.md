# 使用说明

**将 dll 放置在游戏的 mods 文件夹，游戏加载完成后浏览器打开本地 IP 加 8790 端口即可点歌，例 `127.0.0.1:8790`。**

- 手机同网访问：把 `127.0.0.1` 换成启动日志里「手机(同网)」那个地址（例 `192.168.3.2:8790`）
- 端口被占就改 `SongRequestMod.toml` 里的 `网页端口`
- 手机连不上通常是 Windows 防火墙挡入站，管理员 CMD 跑一次：
  `netsh advfirewall firewall add rule name="SongRequest" dir=in action=allow protocol=TCP localport=8790`

---
## 一、装什么

| 文件 | 放哪 |
|---|---|
| `SongRequestMod.dll` | `<游戏目录>\Mods\` （例如 `H:\街机1.70\Package\Mods\`） |
| `page.html` | `<游戏目录>\Mods\SongRequestMod\page.html` |
| `overlay.html`（可选，给 OBS 用） | `<游戏目录>\Mods\SongRequestMod\overlay.html` |
| `SongRequestMod.toml` | 首次启动会自动生成在 `<游戏目录>\`（游戏目录 = 装 游戏主程序 的那层） |

不需要 python、不需要额外依赖。装完**重启游戏**，日志里会出现一行：

```
[SongRequestMod] v1.0.0.0  点歌台: http://127.0.0.1:8790/
```

> 日志默认只输出这一行 + 报错。要排查就把 toml 里 `详细日志=true` 打开。

## 二、网页怎么用

- **搜索**：曲名 / 艺术家 / 曲目 id 三样一起搜，支持空格分词（AND）、全角半角归一。输入 `15001` 直接精确命中，输入 `150` 也能找到 id 含 150 的曲子。
- **封面**：列表里就是游戏里的曲绘（mod 把游戏贴图实时编码成 PNG 给你，不是外部图源）。
- **难度**：每首曲子右侧 5 个难度块（BASIC / ADVANCED / EXPERT / MASTER / Re:MASTER）+ 等级（`13+` 这种原样来自游戏等级表）。点某个难度块 = **直接点这首歌的这个难度**。
- **谱面类型**：曲名旁边是 `DX` / `STD` 徽章（同时有 DX 和标准谱面的会两个都显示）。筛选行里有「谱面」分段控件可按 DX / 标准过滤。
- **实时同步**：曲库会跟着游戏走 —— 你装了什么歌、热导入了什么歌，网页右上角 `rev` 变化时会自动重拉列表（不会丢你的搜索词/筛选/高亮）。也有 `⟳ 刷新曲库` 手动强刷。
- **键盘**：`/` 聚焦搜索、`Esc` 清空、`↑/↓` 移动高亮、`Enter` 点当前高亮曲、`R` 随机点一首。
- **右侧「现在在玩」面板**：曲名 / 难度 / 类型 / **Combo** / MaxCombo / 分数（4 位小数）/ CRITICAL PERFECT·PERFECT·GREAT·GOOD·MISS 判定 / Life。这一块等于把单独的 ComboWeb 顶掉了，不用再装它。
- **随机点歌**：`POST /api/random`（网页上按 `R`）。

### 点歌的行为

- **必须在选曲界面**才能跳（游戏里正在打歌 / 标题画面时，网页会回一句「当前不在选曲界面」）。
- 点难度后：游戏**跳到那首歌**，并且**自动切到难度选择画面、难度光标停在你点的那一档**。之后你按机台开始键就行。
- 该曲没有这个难度时，自动退到它最高的可用难度，并在回复里告诉你实际选了哪档。

## 二·五、别名搜索（社区昵称）

mod 自带一份别名库：`Mods\SongRequestMod\aliases.txt`（约 1080 首、8600+ 条别名，含中文昵称 / 罗马音 / 英文缩写）。

**你可以直接编辑这个文件**，制表符分隔，`#` 开头是注释，保存后**刷新网页即生效**（不用重启游戏，也不用重启 mod）：

```
# 曲名(或曲目 id) <Tab> 别名 <Tab> 别名 ...
独サカリ	咬	甘噛
15001	咬
Don't Fight The Music	dftm	donfai	刹那	你不许玩了
```

匹配规则和 SongSearch 一样朴素：**大小写不敏感的子串匹配**，搜索词按空格分词、每段都要命中（曲名 / 艺术家 / 曲目 id / 任意别名 之一）。搜索命中的是别名时，行上会标出「别名命中: xxx」。不做拼音/罗马音转换 —— 想要什么写法就往文件里加一列。

> 别名来源：从社区版搜歌 mod（SongSearch）的曲库数据里提取整理，按曲名匹配到游戏曲目，所以换游戏版本也能用。

## 二·六、DX / 标准 与「这档谱能不能玩」

- 每首歌带 `DX` / `STD` 徽章（同时有 DX 和标准谱面的显示两个），筛选行可按 DX / 标准过滤。
- **能不能点某档难度以游戏自己的判断为准**（游戏选曲数据里的 `isExistsScore`）：这个版本没有的谱面（文件缺失/版本没同步）会**置灰不可点**。
- 万一你点了游戏认为不能玩的档，回复里会直说，例如：`已跳转: xxx [MASTER] (该曲 Re:MASTER 这个版本不能玩, 游戏自己退到 MASTER)`。

## 三、OBS 用的浮层（可选）

浏览器源加 `http://127.0.0.1:8790/overlay` —— 透明背景，只有曲名/难度/Combo/分数/判定/Life。
（`?bg=1` 会带深色底；`.html` 里的 CSS 随便改，改完刷浏览器即生效。）

## 四、本机 HTTP 接口（做二次开发/联动用）

只监听 `127.0.0.1`，不对外网开放。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 点歌台页面（磁盘上的 `Mods\SongRequestMod\page.html`，改完刷新浏览器即生效，不用重启游戏） |
| GET | `/overlay` | OBS 浮层页面 |
| GET | `/api/songs[?refresh=1]` | 全部曲目：`id / name / artist / genre / bpm / version / type("DX"\|"STD"\|"DX+STD") / std / dx / maxLevel / alias[] / difficulty[5]{type,name,level,levelStr,enable,playable}` |
| GET | `/api/nowplaying` | 当前状态：`state("idle"\|"select"\|"playing")`、曲目、难度、type、`combo / maxCombo / score / life / notes / player / trackNo / judge{criticalPerfect,trueCritical,perfect,great,good,miss}` |
| GET | `/api/status` | `{ok,version,songs,rev,aliases,aliasSongs,state,inSelect}` —— `rev` 是曲库版本号，变了说明曲目表变了（网页靠它自动刷新） |
| GET | `/api/selfcheck` | 自检：补丁/进程/子序列/分类数/光标/布防状态 |
| GET | `/api/selftest?id=&diff=` | 布防：下次进选曲界面自动点这首歌这个难度（验证链路用） |
| POST | `/api/play` | 表单 `id=` `diff=`（diff 省略=该曲最高难度）→ `{ok,msg}` |
| POST | `/api/random` | 表单 `diff=`（可选）→ `{ok,msg}` |
| GET | `/jacket?id=&s=1` | 曲绘本体 PNG（`s=1` 是小图）。取不到返回 404 |

判定字段用的是游戏 `GameScoreList` 里的 `CriticalNum / PerfectNum / GreatNum / GoodNum / MissNum`，Combo 用 `GamePlayManager.GetCombo/GetMaxCombo`。

## 五、配置 `SongRequestMod.toml`

```toml
启用=true
网页=true
网页端口=8790
跳转后进难度画面=true   # 关掉=只移动光标, 不切到难度画面
封面服务=true
详细日志=false
```

## 六、实现要点（给要改的人）

- **曲目表**：`DataManager.GetMusics()` / `GetMusic(id)` 会被别的 mod（MuNet 云海/AquaMai 的 Collection 钩子）用 Harmony postfix 换成服务器下发的几首 —— 所以 mod 直接反射读 `DataManager` 的私有字段 `_musics`（本地全量表）。
- **难度**：这个私服包里所有 `<Notes>` 的 `notesType` 都是 0，难度必须**按 `notesData` 的位置**算（0=Basic … 4=Re:Master），位置也正好对应谱面文件 `015001_03.ma2` = Master。
- **跳曲**：`MusicSelectProcess` 的 `CurrentCategorySelect` / `CurrentMusicSelect` / `ScoreType` / `CombineMusicDataList` / `MonitorArray[i].SetScrollMusicCard|SetScrollGenreCard|OutGenreTab` / `ChangeBGM()` / `CalcMonitorDifficulty(true)`，再写 `CurrentDifficulty[p]` + `DifficultySelectIndex[p]`，最后把子序列切到 `SubSequence.Difficulty`(=3)。
  ⚠ 顺序有讲究：`CalcMonitorDifficulty` 会按曲子默认值覆写难度索引，必须放在设难度**之前**。
  ⚠ 游戏里 `Process.SubSequence` 既是枚举名又是命名空间名，静态引用必撞 —— 子序列数组一律反射拿、反射调。
- **线程**：网页线程只入队，Unity/游戏对象一律在主线程（`OnUpdate`）里碰 —— HTTP 线程直接动游戏对象会偶发崩。
- **曲绘**：AssetBundle 里的贴图多半不可读，走 `RenderTexture` + `ReadPixels` 回读，顺便缩到 512px，再 `EncodeToPNG`；结果按 `id` 缓存。
